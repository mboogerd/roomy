# T6 — A meeting's canvas leaves Roomy as one file that opens anywhere

**Status:** merged (C3 PASS)
**Model:** gpt-5.6-luna @ max · **Escalate to:** gpt-5.6-sol @ xhigh
**Wave:** 3 · **Branches:** `ticket/T6`

## Context

Roomy turns live speech into a shared canvas of mermaid diagrams. Read `CLAUDE.md`.
After T2 (on `main`), rooms live at `/r/<slug>` and the server is `src/server.ts`,
node:http with an exported start function. Rooms are in memory and reaped ten minutes
after the last participant leaves — after that, the canvas is gone.

## Problem

There is no way to take a canvas out of Roomy. The only artefact of a meeting is a
browser tab that will be reaped.

## Solution direction

`GET /r/<slug>/export` returns one self-contained HTML file: every block's title and
source, the transcript, who was present, and the room slug and time. It must render
correctly with **no network access**.

Decided: mermaid renders on open, client-side, from a copy of `mermaid.min.js` inlined
into the file. Add `mermaid` as a runtime dependency solely so the server can read
`node_modules/mermaid/dist/mermaid.min.js` at request time; do not import it in server
code. This avoids any server-side rendering (which would need a DOM) and any round trip
of SVG from browser to server. The file is a few megabytes; that is fine.

The exported page needs no interactivity: blocks in canvas order, each with its title,
mermaid blocks rendered by `mermaid.run()` on load, markdown blocks with the same tiny
markdown-to-HTML conversion the live page uses (copy it; do not share code across the
two files), then the transcript, then participants. Escape everything that came from
the model or from people. Style it plainly; it should look like the live canvas's
cousin, not its twin.

Add an "Export" control to the live page that opens the route in a new tab.

Latitude: the export page's layout and styling; how the transcript is kept for export
(the room must retain utterances — it may already, via T3's journal). Not open: PDF,
image export, a sharing backend, server-side mermaid rendering.
